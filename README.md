## Publish with GitHub Pages

1. Upload these files to the root of the repository on the `main` branch.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select **main** and **/ (root)**, then save.
4. Use the public URL shown by GitHub Pages after deployment finishes.

No installation or build step is required. Keep `index.html`, `styles.css`, `app.js` and `.nojekyll` together. Relative asset links support both an account Pages site and a project Pages site.

The 3D integration map and application illustration are conceptual. They do not connect to healthcare systems or contain patient data. This publication folder excludes private documents, credentials and original resume files.
